# Roadmap

## P0：建立可靠基线

- 为天赋分配、退点、武器组和升华路径补充自动化测试。
- 将 Build 状态接入桌面版已有的保存/打开 JSON 接口。
- 固定并记录外部数据版本，避免上游更新造成无提示行为变化。
- 增加许可证与第三方数据归属清单。

## P1：拆分核心模块

- `Graph`：节点、边、空间索引与路径查找。
- `Allocation`：普通点、升华点、武器组与撤销/重做。
- `Renderer`：Canvas 绘制、相机、命中测试和图集。
- `RuleEngine`：条件显现、树外天赋和珠宝改树规则。
- `I18n`：名称、属性文本和搜索规范化。

## P2：数据与珠宝

- 把 `tools/jewel-compiler/dist` 接入 Planner。
- 优先完成普通范围珠宝、From Nothing、Controlled Metamorphosis 和 Voices。
- 为 Timeless Jewel 设计可复现的查表数据与版本策略。
- 支持数据完整性校验、缓存更新状态和回滚。

## P3：产品化

- 完成 Build 导入、导出和版本迁移。
- 增加 Windows 打包、版本号、图标与发布流程。
- 在真实 PoE2 数据集上增加性能基准与回归测试。
- 根据实际功能确认产品名称、版权说明和发布许可。
